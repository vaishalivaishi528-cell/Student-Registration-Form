# Student-Registration-Form


Project Description

The Registration Form is a simple and user-friendly web application that allows users to register by entering their personal details. It contains input fields for Name, Email, Password, and Bio.

The application includes basic form validation to ensure that all required fields are completed. It also checks that the password contains at least 6 characters and limits the Bio to 200 characters.

Features

- User Name input
- Email address input
- Password field with minimum 6 characters
- Bio section with a 200-character limit
- Form validation
- Submit button
- Simple and clean user interface

Technologies Used

- HTML
- CSS
- JavaScript

Objective

The main objective of this project is to create a simple registration system and understand how HTML forms, CSS styling, and JavaScript validation work together.
